# AI Product Requirement Generator

An interactive web app built with Streamlit, LangChain, and Google Gemini. It uses a multi-agent workflow—featuring a Business Analyst Agent and a Product Manager Agent—to automatically convert high-level product ideas into comprehensive Product Requirement Documents (PRDs).

## Features
- **Business Analyst Agent:** Evaluates product ideas to extract problem statements, context, business impact, and target personas.
- **Product Manager Agent:** Transforms analysis into structured user stories, functional requirements, non-functional requirements, and risk assessments.
- **Streamlit UI:** Simple interactive interface to input API keys and product concepts.
